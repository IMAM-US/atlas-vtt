## A small editable experiment

Move the author owl to the landing stage or rename its nearby text. The underlying note still identifies the same native seat. Undo the board edit if desired. It will not undo a native message, task, fork or result.

Duplicate that owl if a third perspective is useful. A duplicate is another local appearance, not a new OpenRig node. If the desired meaning really changes, edit the linked interpretation and source record deliberately. Existing Atlas does not maintain that semantic relation automatically.

An owner could delegate ongoing map curation to an agent in a future integration. That should include changing layouts and token forms, while retaining attribution and resolving conflicts with human edits. This project demonstrates the content that such an edit would affect, not an implemented agent-editing API.
